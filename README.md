# The Manna — Restaurant E-commerce & POS

A full-stack restaurant commerce platform combining online ordering, in-store POS workflows, inventory management, sales analytics, affiliate tracking, and administrative reporting.

## Overview

The Manna was built as a production-oriented business application rather than a simple storefront. The platform connects customer ordering with operational workflows used to manage products, sales, inventory, and reporting.

## Key Features

- Online restaurant ordering
- In-store POS workflows
- Product and inventory management
- Sales and reporting dashboards
- Affiliate/referral tracking
- Administrative management
- Responsive customer-facing experience

## Technology

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend/Data:** Prisma, PostgreSQL
- **Deployment:** Vercel

## Engineering Focus

The project demonstrates end-to-end full-stack development, including application architecture, database modeling, API/data access, business workflows, responsive UI, and deployment.

## Project Status

The original custom domain is no longer active. The repository is retained as a portfolio record of the engineering work.
